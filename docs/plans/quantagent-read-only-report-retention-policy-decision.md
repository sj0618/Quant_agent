# 읽기 전용 리포트 보관 정책 결정 기록

## 상태

결정 대기. 이 문서는 `OD-REP-01`의 승인 기록 양식이다. 조은채가 아래 항목을 승인 또는 반려하기 전에는 서비스가 보관 기간, 삭제 방식, 마스킹 범위를 정한 것으로 취급하지 않는다.

## 적용 범위

- 대상: 과거 전략 검증 리포트와 그 화면에 표시되는 재현·지표 근거
- 제외: 새 분석 실행, 투자 추천, 신규 리포트 생성
- 원칙: 보관된 리포트는 현재 추천이 아니라 과거 검증 기록으로만 표시한다.

## 승인할 항목

| 항목 | 선택 또는 값 | 승인 전 상태 |
|---|---|---|
| 보관 기간 | 미정 | 기간을 추정하지 않는다. |
| 만료 뒤 처리 | 미정 | 삭제, 익명화, 추가 보관 중 하나를 결정해야 한다. |
| 열람 권한 | 미정 | 인증 사용자 범위와 역할별 제한을 정해야 한다. |
| 표시 제한 | 미정 | 개인식별정보, 계정 식별자, 내부 운영 메타데이터의 마스킹 기준이 필요하다. |
| 이용자 안내 | 고정 | 읽기 전용, 기준 시점, 검증 범위, 제한 사항을 표시한다. |
| 감사 기록 | 미정 | 열람, 다운로드, 삭제 또는 만료 처리의 보존 범위와 보존 기간을 정해야 한다. |

|---|---|---|---|---|

## WBS 반영 조건

승인 기록이 채워진 뒤에만 `OD-REP-01`을 완료로 갱신한다. 이후 `OD-REP-02`는 이 기록의 보관 기간, 권한, 표시 제한을 코드와 브라우저 증적으로 다시 확인해야 한다.
